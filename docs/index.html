pikevm

A regular expression engine that matches in one linear pass: Thompson's NFA construction, a Pike VM with capture groups, and a sparse set that admits each program counter once per input position.

Everything on this page runs in your browser. No regular expression library is involved on the pikevm side: the parser, the compiler and the VM are all in the inlined bundle. Source on GitHub.

2. The thread set

One column per input position, one row per program counter. A dot means that counter was live at that position. The claim is that no column can hold more dots than the program has instructions, and this is what that looks like.

3. Capture groups

Submatch extraction under the VM, not just a boolean. Capture slots are copied on write, so a thread shares its slots with its siblings until one of them actually writes.
